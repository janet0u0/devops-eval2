# Frontend Despacho - Innovatech Chile

Aplicación frontend del módulo de despachos de Innovatech Chile.

## Tecnologías
- React / Vue
- Nginx
- Docker + Docker Compose
- GitHub Actions (CI/CD)

## Requisitos Previos
- Docker instalado

## Levantar con Docker Compose
```bash
docker-compose up -d
```
